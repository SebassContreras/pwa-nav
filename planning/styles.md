# Styles

- Docs: English, terse, structural. No marketing language.
- Chat: Spanish.
- Code: TypeScript strict, ESM imports with extensions, 2-space indent, Prettier.
- Commits: conventional commits (`feat:`, `fix:`, `docs:`).
- Snapshots: compact interactive-only trees by default; full tree only on demand.
- Lawful-use and language rules are hard rules; the rest are overridable defaults.
